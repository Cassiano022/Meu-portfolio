## 🎨 Funcionalidades do Código
* `Intersection Observer API`: Utilizada no JavaScript para detetar quando o utilizador chega à secção de tecnologias e animar as barras de progresso (`skill-fill`) de forma fluida.
* `Menu Mobile Responsivo`: Sistema dinâmico que recolhe o menu em ecrãs menores e fecha automaticamente ao clicar num link.
* `Header Inteligente`: Adiciona uma classe com efeito blur e sombra dinamicamente ao fazer scroll na página (`header.scrolled`).
